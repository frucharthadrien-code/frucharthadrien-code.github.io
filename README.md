## Publier / mettre à jour

Depuis ce dossier :

```powershell
git add .
git commit -m "MAJ Phare numérique"
git push origin main
git push phare main
```

GitHub Pages se met à jour automatiquement (branche `main`, racine `/`).

## Première mise en ligne

1. Org GitHub : `phare-numerique`
2. Repo public : `phare-numerique.github.io`
3. Remote : `https://github.com/phare-numerique/phare-numerique.github.io.git`
4. `git push -u phare main`
5. Repo → **Settings → Pages** → Deploy from branch `main` / root
