## Publier / mettre à jour

Depuis ce dossier :

```powershell
git add .
git commit -m "MAJ Phare numérique"
git push
```

GitHub Pages se met à jour automatiquement (branche `main`, racine `/`).

## Première mise en ligne

1. Compte GitHub : `frucharthadrien-code`
2. Repo public : `frucharthadrien-code.github.io`
3. `git remote add origin https://github.com/frucharthadrien-code/frucharthadrien-code.github.io.git`
4. `git push -u origin main`
5. Repo → **Settings → Pages** → Deploy from branch `main` / root
